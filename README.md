# Banket — банкетные залы Петрозаводск

Flask-приложение с лендингом. Разметка в Jinja2, стили в чистом CSS (без Tailwind/React). Контент страницы и список залов хранятся в SQLite; правки через админку по секретному токену в URL.

## Установка и запуск

```bash
python -m venv .venv
.venv\Scripts\activate   # Windows
# source .venv/bin/activate  # Linux/macOS

pip install -r requirements.txt

# Скопируйте пример переменных окружения и при необходимости отредактируйте .env
copy .env.example .env
# Linux/macOS: cp .env.example .env

python run.py
```

Откройте в браузере: **http://127.0.0.1:5000**

### Как получить токен для админки

**Вариант 1 — простая строка (удобнее всего).**  
Токен **придумываете или генерируете сами** — это не «выдаётся» сервисом. Задаёте его в `.env` как `ADMIN_SECRET_TOKEN`, затем открываете:

`http://127.0.0.1:5000/<ADMIN_SECRET_TOKEN>/admin/`

Пример генерации случайной строки в Python:

```bash
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

Скопируйте вывод в `ADMIN_SECRET_TOKEN` в файле `.env`.

**Вариант 2 — JWT.**  
Сгенерируйте HS256 JWT с полем `admin: true` (или `role: "admin"`), подпишите секретом `JWT_SECRET_KEY` / `SECRET_KEY`, и вставьте **весь токен** первым сегментом URL (как в варианте 1, но строка будет длинной с точками).

## Переменные окружения

| Переменная | Описание |
|------------|----------|
| `SECRET_KEY` | Секрет Flask (сессии и подпись JWT). В продакшене задайте длинную случайную строку. |
| `ADMIN_SECRET_TOKEN` | Строка доступа к админке: URL вида `http://домен/<ADMIN_SECRET_TOKEN>/admin/`. По умолчанию в коде задан dev-токен — **обязательно смените в продакшене**. |
| `JWT_SECRET_KEY` | Секрет для проверки JWT в пути (если используете JWT вместо простой строки). По умолчанию = `SECRET_KEY`. |
| `DATABASE_URL` | Опционально. URI БД, по умолчанию `sqlite:///instance/banket.db` относительно корня проекта. |

## Админка

Формат URL:

```text
https://<хост>/<токен>/admin/
```

Примеры:

- Простой секрет (рекомендуется): задайте `ADMIN_SECRET_TOKEN=my-long-random-string` и открывайте  
  `http://127.0.0.1:5000/my-long-random-string/admin/`
- JWT: сгенерируйте HS256-токен с полем `admin: true` или `role: "admin"` и вставьте **целиком** первым сегментом пути (как в примере с простой строкой).

Страницы:

- `/<токен>/admin/` — панель и ссылки
- `/<токен>/admin/texts/` — JSON контента лендинга (тексты, пути к картинкам в `static/`, iframe карты)
- `/<токен>/admin/halls/` — список залов, добавление / редактирование / удаление

Загрузка изображений залов сохраняется в `app/static/uploads/halls/`; в полях можно также указать путь вручную, например `images/Sverdlov/Sverdlov.jpg`.

## Что есть на лендинге

- Шапка, hero, блок услуг со слайдером, «Почему мы», залы (из БД), меню, форма заявки, контакты, карта, подвал.
- Форма заявки: обязательный чекбокс согласия на обработку ПДн; проверка телефона (не менее 10 цифр) на клиенте и на сервере.
- Баннер cookie внизу страницы: выбор «Принять» / «Отклонить», запись в `localStorage` и cookie `cookie_consent=...`.
- Страница «Политика конфиденциальности и cookie» — `GET /privacy`, ссылки в подвале, в форме согласия и в баннере cookie.
- Базовая SEO-оптимизация: `title/description`, OpenGraph/Twitter, canonical, JSON-LD (`EventVenue`), `robots.txt`, `sitemap.xml`.

## SEO (техническое)

- `GET /robots.txt` — разрешает индексацию публичной части, закрывает `/admin/` и `/*/admin/`, указывает sitemap.
- `GET /sitemap.xml` — текущая карта сайта (главная страница).
- Админка дополнительно отдаёт заголовок `X-Robots-Tag: noindex, nofollow, noarchive`.
- Для корректного canonical/sitemap в проде проверьте, что сайт открывается по одному основному домену (без дублей с/без `www`).

## Заявки с формы → VK

Форма на главной отправляет `POST /api/booking` (JSON); сервер вызывает VK API `messages.send` и дублирует текст каждому получателю из `VK_NOTIFY_USER_IDS`.

Переменные в `.env`:

| Переменная | Описание |
|------------|----------|
| `VK_ACCESS_TOKEN` | Токен с правом **messages** (см. [документацию VK](https://dev.vk.com/method/messages.send)). |
| `VK_NOTIFY_USER_IDS` | Список id пользователей VK через запятую, например `17713930,611228535,1055522441`. |

**Важно:**

- Токен и id **не храните в репозитории** — только в `.env` на сервере. Если токен когда‑либо светился в чате — **отзовите его** в настройках VK и выпустите новый.

**Nginx (reverse proxy):** передайте в приложение реальный хост и схему, иначе проверка формы и `url_for` могут вести себя иначе, чем локально:

```nginx
proxy_set_header Host $host;
proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
proxy_set_header X-Forwarded-Proto $scheme;
proxy_set_header X-Forwarded-Host $host;
```

В коде включён `ProxyFix` — он использует эти заголовки.
- Для **сообщества**: включите сообщения у группы, получите ключ с доступом к сообщениям; пользователи должны **разрешить** сообщения от сообщества или написать боту первыми (ограничения VK).
- Для **пользовательского** токена действуют отдельные правила VK на отправку личных сообщений.
