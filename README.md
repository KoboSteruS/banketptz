# Banket — банкетные залы Петрозаводск

Flask-приложение с лендингом. Разметка в Jinja2, стили в чистом CSS (без Tailwind/React). Контент страницы и список залов хранятся в SQLite; правки через админку по секретному токену в URL.

## Установка и запуск

```bash
python -m venv .venv
.venv\Scripts\activate   # Windows
# source .venv/bin/activate  # Linux/macOS

pip install -r requirements.txt

# Скопируйте пример переменных окружения и при необходимости отредактируйте .env
copy .env.example .env
# Linux/macOS: cp .env.example .env

python run.py
```

Откройте в браузере: **http://127.0.0.1:5000**

### Как получить токен для админки

**Вариант 1 — простая строка (удобнее всего).**  
Токен **придумываете или генерируете сами** — это не «выдаётся» сервисом. Задаёте его в `.env` как `ADMIN_SECRET_TOKEN`, затем открываете:

`http://127.0.0.1:5000/<ADMIN_SECRET_TOKEN>/admin/`

Пример генерации случайной строки в Python:

```bash
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

Скопируйте вывод в `ADMIN_SECRET_TOKEN` в файле `.env`.

**Вариант 2 — JWT.**  
Сгенерируйте HS256 JWT с полем `admin: true` (или `role: "admin"`), подпишите секретом `JWT_SECRET_KEY` / `SECRET_KEY`, и вставьте **весь токен** первым сегментом URL (как в варианте 1, но строка будет длинной с точками).

## Переменные окружения

| Переменная | Описание |
|------------|----------|
| `SECRET_KEY` | Секрет Flask (сессии и подпись JWT). В продакшене задайте длинную случайную строку. |
| `ADMIN_SECRET_TOKEN` | Строка доступа к админке: URL вида `http://домен/<ADMIN_SECRET_TOKEN>/admin/`. По умолчанию в коде задан dev-токен — **обязательно смените в продакшене**. |
| `JWT_SECRET_KEY` | Секрет для проверки JWT в пути (если используете JWT вместо простой строки). По умолчанию = `SECRET_KEY`. |
| `DATABASE_URL` | Опционально. URI БД, по умолчанию `sqlite:///instance/banket.db` относительно корня проекта. |

## Админка

Формат URL:

```text
https://<хост>/<токен>/admin/
```

Примеры:

- Простой секрет (рекомендуется): задайте `ADMIN_SECRET_TOKEN=my-long-random-string` и открывайте  
  `http://127.0.0.1:5000/my-long-random-string/admin/`
- JWT: сгенерируйте HS256-токен с полем `admin: true` или `role: "admin"` и вставьте **целиком** первым сегментом пути (как в примере с простой строкой).

Страницы:

- `/<токен>/admin/` — панель и ссылки
- `/<токен>/admin/texts/` — JSON контента лендинга (тексты, пути к картинкам в `static/`, iframe карты)
- `/<токен>/admin/halls/` — список залов, добавление / редактирование / удаление

Загрузка изображений залов сохраняется в `app/static/uploads/halls/`; в полях можно также указать путь вручную, например `images/Sverdlov/Sverdlov.jpg`.
